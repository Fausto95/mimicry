# Expo default template

The app `npx create-expo-app@latest` generates (Expo SDK 58), copied unmodified
apart from app identifiers. It is Mimicry's reference "real app": expo-router
with native tabs, Reanimated layout animations, expo-image, expo-symbols and
the splash screen. `scenes/` drives both `mimicry oracle` and simulator
captures.

```sh
npm install
node ../../packages/cli/bin/mimicry.js dev .
```
